# ASBL Residential Projects Showcase
### *Architecture for Living, Not Just Existing*

A premier, award-winning residential real-estate web application engineered for **ASBL (Ashoka Builders India Private Limited)**, showcasing their landmark residential developments across Hyderabad.

---

## 🏛️ Brand Vision & Architectural Creed

Unlike standard real estate portals that treat residences as speculative commodity grids, this website is conceived through the lens of a luxury architectural monograph. It celebrates ASBL's defining design innovations:

- **The Signature Outdoor Living Balcony:** Generously proportioned sky cabanas (up to 200+ sq.ft) extending the living room into the open sky.
- **Monolithic In-Situ Casting:** Tunnel form structural engineering eliminating internal beams, dampness risk, and acoustic leakage.
- **Radical Punctuality:** 100% adherence to Telangana State RERA declared handover milestones.
- **Micro-Climate Engineering:** Computational sun-path and wind-tunnel analysis optimizing year-round thermal comfort.

## ✨ Key Experiences & Features

1. **Bespoke Luxury Loader:**
   - Architectural monogram animation with shimmering concentric rings.
   - Non-linear progress counter (0% to 100%) and editorial quote reveal.
   - Cinematic smooth exit transition.

2. **Editorial Hero Section:**
   - Typographic hierarchy pairing Cormorant Garamond & Cinzel.
   - Architectural image backdrop with subtle parallax.
   - Key statistics bar (7 Projects, 50+ Storeys, 100% On-Time Record, 70%+ Open Expanse).

3. **Interactive Project Showcase (Core Gallery):**
   - Real-time search by project name, location, or corridor.
   - Multi-category filtering: Status (All, Ongoing, Completed), Configuration (2 BHK, 3 BHK, 4 BHK), Corridor (Financial District, Central Hyderabad, Kukatpally, Kokapet, Uppal).
   - View modes: Modern Luxury Grid vs Curated Editorial List.
   - Interactive Architectural Spec Sheet Modal with multi-image gallery carousel, floor plan breakdowns, connectivity travel times, and RERA verification.

4. **Architectural Matrix Comparison:**
   - Compare up to 3 ASBL developments side-by-side.
   - Analyzes configurations, handover timelines, clubhouse sizes, open expanse percentages, and structural storeys.

5. **Strategic Corridor Explorer:**
   - Interactive breakdown of Hyderabad's premier residential corridors.

6. **Private Consultation & Tour Booking:**
   - Client-side form validation (name, phone, email, project, BHK, date).
   - Generates verified reference docket ID with confetti celebration.
   - Clear disclosure distinguishing showcase simulation from live developer CRM.

## 🛠️ Technology Stack

- **Framework:** React 18 & Vite
- **Styling:** Tailwind CSS (Custom ivory, obsidian, champagne, and forest green palette)
- **Motion & Interactions:** Framer Motion (Spring physics, layout transitions, exit animations)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Typography:** Cormorant Garamond, Cinzel, Plus Jakarta Sans, Italiana (Google Fonts)
- **Deployment:** Vercel
